# 我的课表（网页版）

一个纯前端、零依赖的电脑端课表应用：用浏览器打开即可用，数据自动存在本机 `localStorage`。

## 功能
- 周课表网格，支持「大节 / 小节」两种粒度（设置里可切换）。
- 周次导航：`‹ 第 X 周 ›` 按钮、拖动空白处左右滑动切周、拖动课程到边缘停留自动换周并互换。
- 拖动换课 / 调休：拖到空格=移动，拖到已有课的格子=两门课对调时间。
- 单双周、具体周、周次范围（如 `5-8`、`1,3,5`）显隐。
- 导入 / 导出 JSON；图片型 PDF 可走「导入 PDF」做 OCR + 核对（需联网）。
- 自定义学期名、总周数、开学日期、每节时间表。

## 怎么打开
直接用浏览器打开 `web/index.html` 即可；或在该目录下起一个静态服务，例如：

```bash
# 任选其一
python -m http.server 8080
# 或
npx serve web
```

然后访问 `http://127.0.0.1:8080/`。

## 数据模型（网页版 ↔ 小程序版共用）
- `config`：学期、粒度、节次数、星期数、总周数、开学日期、每节时间表。
- `courses[]`：每门课 `{ name, teacher, location, day, start, end, week, color, note }`。
- `view.currentWeek`：当前所在周。

导入示例见 `课表数据.json`（由教务系统导出的 PDF 转写而来）。

## 目录
- `web/`：`index.html` / `styles.css` / `app.js`（主程序）
- `docs/decisions-course-app.md`：设计决策记录
- `课表数据.json`：示例课表数据（可导入）
